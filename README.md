# Automated Plant Watering System 🌱

## 📌 Overview

The Automated Plant Watering System is a smart irrigation project designed to monitor soil moisture and environmental conditions and provide optimized watering for different plant types.

The project was independently designed and developed, including planning, implementation, budgeting, quality assurance, and post-deployment support.

## 🎯 Objectives

- Monitor soil moisture conditions
- Monitor environmental conditions
- Optimize water usage
- Support different plant watering requirements
- Improve plant health through appropriate watering

## 🛠️ Technologies & Concepts

- Embedded Systems
- Sensors
- Soil Moisture Monitoring
- Sensor Interfacing
- Microcontroller-Based Development

## ⚙️ How It Works

1. Sensors monitor soil and environmental conditions.
2. The system evaluates the collected measurements.
3. The watering system responds based on the detected conditions.
4. Water is supplied according to the plant's requirements.
